# 09-brand-and-tokens

- **The CSP took images from 'self' only** (decision changed 2026-11-27, spec chat-images, the `blob:` decision at the top of 09-brand-and-tokens.md). Before: `img-src 'self'`, so a picture the page made from bytes (a `blob:` URL) was refused.
- **Links were underlined only on hover** (until 2026-11-22, the accent decision at the top). Before: `LINK_CLASS` was `text-text-1 hover:underline`, so a link in a sentence (the Spend note's "Change in Settings") differed from the text by colour alone, 2.63:1 where 3:1 is needed (axe `link-in-text-block`). `ID_CLASS` keeps its hover underline.
- **The current sidebar link was filled with `surface-2`** (until 2026-11-22, the `sidebar-active` decision at the top). Before: the active link used `bg-surface-2`, `#F3F2EE` on the `#F3F1EC` sidebar in light (`#EEF2EF` on `#EDF1EE` in the Celadon palette), about 1.01:1, so only the bar and weight marked it there.
- **No page-width tokens** (until 2026-11-20, the page widths decision at the top). Before: the token set had no width; Rules set `max-w-3xl` (768px) itself and the other pages were as wide as `<main>` (1217 to 1232px at 1280 by 800).
- **Type sizes were Tailwind's defaults and had no Tailwind mapping; no shadow tokens** (until 2026-11-19, the type-step decision at the top). Before: `index.css` mapped no `--text-*`, so `text-xl` was Tailwind's 20 px and not the `xl` step (28 px), the token-mapping test skipped `--fs-*` and `--lh-*`, and shadows were Tailwind's defaults.
- **Select was a native select** (until 2026-11-17, the Select decision at the top). Before: `Select` wrapped a native `<select>` (`appearance-none`, with its own chevron), so the browser drew the option list; on macOS it opened over the field and hid the label above the next field, and tests drove it with `fireEvent.change` and read its `options`.
- **The classic page kept its own colours and title** (until 2026-11-16, the no-server-rendered-colours decision at the top). Before: `/classic` and the error pages carried their own hex palette in `src/ui/html.ts` (light and dark, not from `tokens.json`), and the classic page was titled "software-factory status".

## History

- **The palette was the Gongbang brand board, ink and burnt orange** (replaced 2026-11-22, the Celadon decision at the top). Before: light / dark `bg` `#FBFAF7` / `#17171A`, `surface` `#FFFFFF` / `#212125`, `surface-2` `#F3F2EE` / `#2C2C30`, `sidebar` `#F3F1EC` / `#1D1D21`, `nav-active` `#1C1C1E` / `#F2F2F4`, `border` `#E4E2DC` / `#34343A`, `border-strong` `#C2C0BB` / `#59595D`, `text` `#1C1C1E` / `#F2F2F4`, `text-2` `#5E5E63` / `#A1A1A8`, `text-3` `#66666A` / `#93939A`, `accent` `#C2410C` / `#FB923C`, `ember` `#FB923C` in both, `on-solid` `#FFFFFF` / `#17171A`; the owner-approved brand board of 2026-11-11. The Slack app's `background_color` was `#1C1C1E`.
- **The mark was a white 공** (replaced 2026-11-22, the Celadon decision at the top). Before: The mark is a white bold 공 on a rounded `#1C1C1E` square on the macOS icon grid (an 824 px square, radius 185, on 1024), with the 공 drawn as outlines (its ㄱ, ㅗ and the ring of ㅇ) so no installed font is needed, and an ember dot (`#FB923C`, the `ember` token in both themes) top right, at (800, 224) with radius 44 on the 1024 grid, drawn at every size (decision changed 2026-11-12: it was drawn only at 64 px and up, see History). At 32 px and below its radius is at least 2.5 px at that size (`data-small-r="2.5"` on the circle, read by the builder: radius `max(44, 2.5 × 1024 / size)`, so 80 at 32 px and 160 at 16 px, where it overlaps the ㄱ's top-right corner by about 1 px). The sidebar mark draws the same circle with the `fill-ember` class at the 24 px radius.
- **Tabs copied SegmentedControl's look** (replaced 2026-11-15). Before: a 32px box with a 1px `border-strong` edge on `surface` holding 28px tabs, the selected tab filled `accent` with `on-solid` text, hover `surface-2`; the Add project "+" was a separate bordered button beside the row.
- **App on `surface`, no sidebar colour** (replaced 2026-11-13). Before: the app wrapper painted `bg-surface` (`#FFFFFF` light, `#212125` dark) on every page, and the sidebar had no token of its own, so it did not differ from the content.
- **Design gallery page in the dashboard** (replaced 2026-11-13). Before: a "Design system" page in the System group of the sidebar (route `/app/design`) showed every shared component in each variant, size and state, and `tests/web-design-system.test.tsx` failed when an exported component was missing from it. Now the design system is `design-system/` and `web/src/components/ui/` only.
- **No product name or mark** (replaced 2026-11-12, phase 3). Before: the app was "Software Factory.app" with Electron's icon, the menu bar said `SF <n>`, and the dashboard's title and sidebar said "software-factory" with no favicon.
- **Token source and generated CSS** (new decision, 2026-11-11). Before: each file chose Tailwind palette classes (`text-blue-700`, `dark:text-zinc-400`) and nothing stopped a hex colour.
- **Pages on token classes** (new decision, 2026-11-12, phase 2). Before: pages chose Tailwind palette classes with `dark:` variants and `rounded-md`; phase 1 left them as they were.
- **Colours equal the Tailwind palette** (replaced 2026-11-12, phase 4). Before: every colour value equalled the Tailwind palette colour the pages used (zinc, blue, emerald, amber, red, as oklch), so phase 1 changed no look; type was sizes only, card radius was 8 px and there was no 10 px step.
- **Three button kinds** (replaced 2026-11-12, components). Before: the button kinds were ghost, outline and the dialog's destructive confirm (the theme's red variable, which `tests/web-dialog.test.tsx` pinned), with each page sizing buttons with its own classes (`buttonClass`, `tab`, `textButton`) and styling raw selects, inputs and textareas itself.
- **Danger without a border** (replaced 2026-11-12, controls follow-ups). Before: the danger variant was `failed` text with no border (0 px beside secondary's 1 px), Merge sat 8 px under the verdict row, the Tasks views were toggle buttons in a ButtonRow, the Settings models fields sat inline with their labels and Save on the last field's row, and the Rules empty-state button sat 8 px under its box.
- **Ember dot only at 64 px and up** (replaced 2026-11-12). Before: the ember dot was `#FF6A2B`, not a token, drawn only at 64 px and up (`data-min-px="64"`), and the sidebar mark left it out, so the 24 px mark and the 16 and 32 px favicon showed no dot.
- **The favicon refused by the app's CSP** (replaced 2026-11-12). Before: the app's CSP was `default-src 'none'; script-src 'self'; style-src 'self'; connect-src 'self'; form-action 'self'; base-uri 'none'; frame-ancestors 'none'`, with no `img-src`, so the browser refused `/app/favicon.png` and every dashboard page logged two console errors; `npm run check:responsive` did not read the console and passed.
- **No `bg-sidebar` utility** (until 2026-11-19, the every-token-has-a-name decision at the top). Before: `web/src/index.css` mapped no `--color-sidebar` (nor running, done, the pill borders, `--radius-box` or the spacing steps), so the sidebar painted `bg-(--sidebar)` and there was no `bg-sidebar`, `text-running`, `text-done` or `rounded-box` class.
- **Accent coloured links, IDs, the selected segment and the Select check** (until 2026-11-19, the accent decision at the top). Before: `LINK_CLASS` was `text-accent hover:underline`, the selected SegmentedControl segment was filled `accent` with `on-solid` text, and the Select check was `text-accent`, so orange stopped meaning the primary action.
