- **The Settings part of the Tasks and Settings polish decision** (moved here 2026-11-21 from that decision in 09-dashboard-tasks.md, for the topic size cap; not a changed decision). **Settings:** the models grid is `grid-cols-[max-content_7rem]`; the card layout shows Value under Key and labels Source, File value, Applies at and Reset; a millisecond key's File value reads like its Value (`30m`); a default is always `default: <value>` and an empty file value or default is `empty`; `hold_policy` is a select with `hold` (mode hold), `start` (mode run) and `wait` (mode run_after_minutes, with a minutes field that starts at 20), each labelled with the server mode's meaning, saved as `{"mode":"hold"}`, `{"mode":"run"}` or `{"mode":"run_after_minutes","minutes":N}`, a server refusal shown beside it; the message_style example is the paragraph only (no placeholder); the per-project line is "This project: uses the global value" or "This project: <value> (<source>)"; the Commands paragraph is "Commands act as <id> (from config|environment)" with no how-to-act sentence.
