## History

- **Runners named revisions, slots and pids in its text** (until 2026-11-20, the plain words decision at the top). Before: "Factory running: revision {rev}, since {time}.", "Worker setting: N (override | config file | default)", each process row "host · pid N · started … · B busy, I idle, S slots, max M" with a "draining" badge, and "Running revision {rev}" with "up to date with origin/main", "N commits behind origin/main" or "origin/main not checked yet".
- **Runners used Sections** (until 2026-11-19, the Cards decision at the top). Before: Processes and Running now were `Section`s with no surface, and no process was an `Empty` line.
- **The banners and the migration row named `npm run`** (decision changed 2026-11-16, the Migrate now, Start and Restart now decision at the top). Before: the stopped banner said "Start it with npm run factory -- dev.", the migration banner "Update to {target} waits for npm run migrate.", and the Needs-you migration row's command was `npm run migrate`; the page had no button for either.
