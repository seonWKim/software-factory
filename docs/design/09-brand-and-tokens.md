# 9. Brand and design tokens

- **One token source, generated CSS (new decision, 2026-11-11, phase 1).** `design-system/tokens.json` is the only place a dashboard colour, type size, spacing step or radius is defined: light and dark colours, status pill colours (ok, warn, bad, info), type sizes, spacing and radius. `scripts/build-tokens.mjs` (`npm run build:tokens`) writes `web/src/tokens.css` from it: light values on `:root`, dark values under `.dark` (the class the theme toggle sets). The output is deterministic and carries a header that names the script; nobody edits it. `web/src/index.css` imports it and maps the Tailwind theme (`@theme inline`), so `bg-surface`, `text-text-2`, `bg-accent` and `rounded-card` exist. Every colour value equals the Tailwind palette colour the pages use today (zinc, blue, emerald, amber, red), so phase 1 changes no look.
  - **The hex rule.** No file under `web/src/` except `tokens.css` holds a hex colour (six or eight digits always; three or four only when a letter a-f is among them, so `#192` is not flagged). `tests/design-system.test.ts` enforces it, and fails when `tokens.css` differs from the generator's output.
  - **Phase 2 is done (2026-11-12).** Every view, component and `LINK_CLASS` under `web/src/` uses token classes (`text-text-1/2/3`, `bg-bg`, `bg-surface`, `bg-surface-2`, `border-border`, `border-border-strong`, `text-accent`, `outline-focus`, `bg-pill-*-bg text-pill-*-fg`) and `rounded-control`, `rounded-card` or `rounded-pill`; no `dark:` variant is needed because the tokens switch with `.dark`. `tests/design-system.test.ts` fails on a Tailwind palette colour class, a default radius class or an arbitrary `text-[...]` size. The pages' own light/dark choice still comes first (`web/src/theme.ts`: stored choice, then `prefers-color-scheme`), covered in `tests/ui-shell.test.tsx`. The three button kinds are ghost, outline and the destructive confirm (still the theme's red variable, which `tests/web-dialog.test.tsx` pins; moving it to `pill-bad` is a follow-up). The `/classic` page keeps its own CSS.
  - **Not built yet.** A written brand brief; the `/classic` page's colours.
