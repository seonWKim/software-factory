  - **Model input.** One `LLMProvider.complete` call (`standard` class, JSON output `{ sql }`): the instruction, the question, today's UTC date (the Spend page's day), and each table's and column's name with its line and meanings. Hidden columns are left out; no row value and no row count is sent. The request passes the egress scan (`log` channel) first; a flagged request is not sent (400).   - **Query checks and connection** (`FactoryStore.readOnlyQuery`, `src/impl/store/sqlite/readonly-query.ts`). Before running: one statement (one trailing `;` allowed) that begins with `SELECT` or `WITH` and has a `SELECT`; ATTACH, DETACH, PRAGMA and every write or transaction word anywhere in the code (comments and string literals blanked) is refused, each with its reason (422 with the query and `refused`). A query that names a hidden column (`HIDDEN_COLUMNS`, quoted or not) is refused the same way; a result column with a hidden column's name shows `[hidden]`, and the query's reads of hidden columns give NULL. The query runs in a child process (`readonly-query-worker.ts`) on its own connection, opened read-only (`readOnly`, SQLITE_OPEN_READONLY) with `query_only` on and, on Node 24.10 and later, an authorizer that allows only reads; each of the three refuses a write alone. At most 500 rows (`truncated` when cut); past 5 seconds the child is killed and the query refused with a time-limit message. Why a process: `node:sqlite` cannot interrupt a running statement, a process can be killed.
  - **Results.** Every text cell, the query text and the column names pass the Withholder (`[withheld: <rule>]`). The response: `{ as_of, sql, columns, rows (arrays, in column order), truncated, answer }`.
  - **Cost.** Each model call writes one `data ask: model call` log record (model class, provider, input and output tokens, `cost_usd`) through the page's logger. It is not in the Spend totals: spend counts run outcomes only (06-spend), and the Ask has no run and no table of its own.

The table list shows each table's owner and line under its name; the table card shows the line, `Owner: <component>`, and the column meanings (also as the column header's title). Strings are `data.*` keys in `web/src/i18n/en.ts`.
  - Not built: typed SQL when the model is off, saved questions, charts, any write.
