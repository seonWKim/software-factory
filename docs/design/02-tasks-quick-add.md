# 2. Plain tasks: quick add

- **Quick add reports the words it did not read, and no duration is assumed (decision changed 2026-11-20, wi_a03550f9, "Quick-add shows what it parsed"; current; replaces "the row's duration text (30 minutes shown when none is stored)" from the no timeline decision in design 02-tasks-page, see History).** The decision that changed: **`parseQuickAdd` (`src/core/quick-add.ts`) returns `unread` beside the task: each `every …` that is not the repeat at the end (`every` with its next plain word, or `every` alone), kept in the title; and a task with no typed duration stores none and shows none.** Owner answer 1: the repeat stays end-only, and other `every …` words are flagged in the dashboard's quick-add preview (design 09-dashboard-tasks) rather than read. Owner answer 2: no duration is written at add time (the store already stored null) and the Tasks row no longer shows 30 minutes for it; the planner's own scheduling default was removed with the timeline (2026-11-16), so nothing in planning changes. `GET /api/v1/tasks/preview` runs the same parser read-only for the preview. Existing tasks keep any stored duration (no backfill).
  - Tests: `tests/quick-add.test.ts` (unread words, end-only `every`, no duration), `tests/tasks-api.test.ts` (a timed task added without a duration stores null).
- **A quick-add `#label` takes letters and digits of any script (decision changed 2026-11-16; current; replaces "`#label` is ASCII letters, digits, `_` and `-`", from the #606 quick-add decision below, see History).** The decision that changed: **the `#` tag is `#` then one or more Unicode letters or digits, `_` or `-` (`/^#[\p{L}\p{N}_-]+$/u`), so `#집` or `#買い物` is the list and leaves the title, as `#home` does.** `월세 내기 금요일 p1 #집` adds the task `월세 내기 금요일 p1` in list `집`: weekday names and `p1` are not quick-add tokens and stay in the title. A `#` with nothing after it, or with other punctuation (`#집!`, `#home.x`) or an emoji, is a title word as before. `#label` stays the list, not a `+slug` project, and `parseQuickEdit` reads the same rule. The Tasks page placeholder now shows only forms the parser reads: "e.g. rent tomorrow !1 #home, then {key}" (it promised `friday` and `p1`, which were never parsed). Code: `scan` in `src/core/quick-add.ts`, `tasks.addPlaceholder` in `web/src/i18n/en.ts`; tests: `tests/quick-add.test.ts`, `tests/ui-tasks-quick-add.test.tsx`.
- **Quick add reads a repeat only when `every day`, `every week` or `every month` ends the text (decision changed 2026-11-15; current; replaces "`every` anywhere starts a repeat, and any other `every` form is refused", from the #606 quick-add decision below, see History).** The decision that changed: **the recurrence is the last two words of the text, and only when they are `every day`, `every week` or `every month` (any case); any other `every …` is title words.** So "Design rules checked on every UI review" is a task with that exact title, and "water plants today every week" repeats weekly, while "water plants every day today" is titled "water plants every day" with no repeat. Weekday forms (`every monday`) are not repeats (owner answer 1): they stay in the title. The "unknown recurrence" refusal is gone; a repeat with no due day is still refused. `parseQuickEdit` (`task edit`, the Tasks page's edit) reads the same rule. Code: `scan` in `src/core/quick-add.ts`; tests: `tests/quick-add.test.ts`.

- **The quick-add parser (from the 2026-11-11 plain tasks decision, design 02-tasks).**
  - **Quick-add.** `src/core/quick-add.ts` is a pure parser (no clock, no I/O, no import from outside `src/core`). It picks out, in any order: `today`, `tomorrow`, `YYYY-MM-DD` (the due day); `HH:MM` (the due time; alone, due today); `!1` to `!3`; `#label`; `every day`, `every week`, `every month` (since 2026-11-15 only as the last two words, see the quick-add repeat decision at the top). The words left are the title. It refuses, with a reason and nothing stored: a date or a time that does not exist (`2026-13-01`, `25:00`), a priority outside 1 to 3, a field given twice, a recurrence with no due day, and an empty title.
