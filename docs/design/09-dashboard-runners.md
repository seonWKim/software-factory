# 9. Status page: dashboard Runners page

- **Migrate now, Start and Restart now are buttons, and no banner names `npm run` (decision changed 2026-11-16, phase 3 of 4 of local-0ffe3059-d863-4717-b3eb-1c72a06e444e; current; replaces the stopped and migration banners' `npm run` commands and the Needs-you migration row's `npm run migrate`, see History).** The decision that changed: **the page acts on the supervisor itself** (design 08-self-update). `SupervisorActions` (`web/src/views/system-banner.tsx`) reads `GET /api/v1/supervisor` and draws the buttons it offers, each behind the shared `Dialog`; when it offers none, it shows the first refusal's plain-words reason instead, and nothing while the read fails (an older server). The Runners page's `FactoryBanner` shows Migrate now while an update waits for its migration, else Start and Restart now; the Needs-you migration row shows Migrate now, and its command reads "Migrate now, or factory migrate". Migrate now's dialog shows the dry run (the pending steps and each line it prints) before its confirm is enabled; the confirm starts the migration and the banner follows it through `supervisor.json`. `postMigrate` and `postSupervisor` (`web/src/api.ts`) send the CSRF token from the same read. The texts: "Factory stopped. No runs start. Start it from a terminal with factory dev." and "Update to {target} waits for its migration[ (pending: …)]: Migrate now applies it." The server-rendered `/classic` page keeps its own wording.
